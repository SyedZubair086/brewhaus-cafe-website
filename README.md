# ☕ BrewHaus — Premium Café Website

A modern, responsive, and visually appealing café website developed as part of my **Web Development Internship — Week 1 Project**.

BrewHaus is designed to provide a premium café experience through a warm visual theme, clean layout, responsive design, and user-friendly navigation. The project focuses on building a professional multi-page business website using HTML, CSS, and JavaScript.

## 🌟 Project Overview

The goal of this project is to create a professional online presence for a café where visitors can explore the website, browse the menu, view café-related content, and find contact or reservation information.

## ✨ Features

- 🎨 Premium and warm café-inspired design
- 📱 Responsive layout for desktop, tablet, and mobile devices
- 🏠 Attractive homepage with a modern hero section
- ☕ Dedicated menu page for café items
- 🧭 Simple and user-friendly navigation
- 💻 Clean and organized HTML, CSS, and JavaScript
- ♿ Focus on accessible and semantic HTML structure
- ⚡ Lightweight frontend implementation

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic markup
- **CSS3** — Styling, layouts, Flexbox, Grid, and responsive design
- **JavaScript** — Interactive website functionality
- **Git & GitHub** — Version control and project hosting

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/SyedZubair086/brewhaus-cafe-website.git
   ```

2. Open the project folder:

   ```bash
   cd brewhaus-cafe-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
